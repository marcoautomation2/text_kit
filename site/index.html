Text Kit

A library of small text helpers: padding, slugs, word counting and truncation.

  • rank core200
  • text

Download the zip

text_kit_lib.zip

How to use it

  1. Download the zip.
  2. Copy the zip into a Fearless project, zipped or unzipped. The code of the project can then use the library.
  3. Write use text_kit.TypeName as TypeName; in the rank file of the package that needs the library.

The package of the project needs a rank higher than core200. Every app qualifies.

What is inside

  • Pads: .left, .right and .center.
  • Words: .of, .count and .title.
  • Slugs: .of.
  • Truncs: .to.

The folder example of the source holds a small app that uses the library.
